Privacy policy

Last updated: 6 November 2026

The Vale is a personal tool used only by its maker, Roko Grga, on his own computer. It is not offered to anyone else.

What it accesses

With the owner's consent, The Vale uses Google's OAuth to read the owner's own YouTube channel through the YouTube Data API and the YouTube Analytics API, using read-only scopes (youtube.readonly, yt-analytics.readonly). It reads channel and video statistics such as views, watch time, average view percentage, subscribers gained and audience retention.

How the data is used

The statistics are used only to measure the owner's own videos and to improve how future videos are planned and edited.

Storage and sharing

The access token and the statistics are stored only on the owner's own computer. Nothing is sent to any server of The Vale (there is none), sold, or shared with third parties. The Vale's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time at myaccount.google.com/connections; deleting the token file on the owner's computer removes the stored access too.
