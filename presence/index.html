The Vale's Presence

A YouTube studio run by Claude Code agents.

You drop in footage. The agents plan, cut, add overlays, cut Shorts, research titles and thumbnails, and get the upload ready. They measure every cut and you go through the list. Once you approve the talk, nothing can change a word of it.

Runs on your own PC, on your own Claude Code login. No API key, nothing else to pay for.

What it does

The agents do the work. You make the calls.

A screen laid out like a video editor, in a pixel-art frame. Every stage shows how long it took and what it cost.

The approved talk is locked

When you press Approve & lock, the rough cut's edit list and video are fingerprinted. Before and after every later stage they're checked again. If anything changed a word, the project stops and says which file changed and at which stage. Visuals, fixes or a confused agent can't touch what you approved.

✓ Approve & lock · rough.mp4, edl.json ✓ Visuals · voice matches the rough ✓ Fix one label · voice matches ✗ edl.json changed at Visuals · project halted

Every cut is measured

Every word is transcribed. Silences, fillers, retakes and asides are measured and cut, and each join is checked on the sound so no word gets clipped. Every cut is listed with Before and After clips.

Fixes take seconds

Only the overlay windows and the stretches of the final that changed are rendered again. One label fixed in a finished 10-minute video took 36 seconds.

Agents sleep while it renders

A long render runs in the background and wakes the agent when it's done, so no agent sits waiting on a progress bar.

The whole studio

Plan, script, record, edit, Shorts from a long video, title and thumbnail research, thumbnail options, your thumbnail next to real ones in a feed, and the upload.

You see what the agent reads

Every skill, rule and context file each stage reads, editable in place. Skills switch on and off per stage, and a house rules book learns from your corrections.

Take it anywhere

Export to MP4, SRT subtitles, and FCPXML or OTIO, so the cut opens in another editor.

How a project goes

Nine stages, four of them yours

Tap a stage. The ones marked ★ wait for you: nothing is uploaded until you press the button.

The agent

Ask

The agent asks what it needs to know about the video and writes the brief.

The agent, then you

Plan & record

Only when you start from an idea. The agent looks at titles and thumbnails of videos like yours and writes a plan you approve. Then you record and drop the footage in.

The agent

Rough cut

Every word is transcribed. Silences, fillers, retakes and asides are measured and cut, and every join is checked on the sound so no word is clipped.

You

Rough review

Watch the rough and go through the cuts, flagged ones first, with Before / After, Keep, Restore or a note. Strike words in the transcript. Then Approve & lock, or send it back with your notes.

The agent

Visuals

Labels, cards, punch-ins, captions and sound go on top of the locked rough, from an overlay kit. A proof first, then the final.

The agent

Inspect

The agent checks the final against a checklist: length, the locked voice, the frames, text inside the safe areas.

You

Final review

Approve it or send it back. A fix renders only what changed.

You

Titles & thumbnails

Options as cards, with your thumbnail shown in a feed next to real videos.

You

Upload & export

The upload happens only when you press the button. Export gives you the video, the subtitles and the edit list for other programs.

Four recipes to start from: Edit a video (footage you have), A video from the idea, Edit a Short, and Shorts from a long video, where the agent picks the moments and you keep or drop each one.

Get started

Up and running

git clone https://github.com/WebGrga/the-vales-presence
cd the-vales-presence
npm install && npm install --prefix engine/remotion
npm start

It opens on localhost:4848. If something is missing, the Setup tab checks every requirement and gives you the command that fixes it.

You need

  • Claude Code, logged in. The agents run on that login.
  • Node.js 22, ffmpeg, Python 3.10+ with numpy and Pillow, and uv.
  • About 20 GB free for a long video's render cache.
  • A GPU is optional: NVIDIA, Intel, AMD and Apple encoders are found by themselves.

Honest limits

What it doesn't do yet

  • Tested on real footage on Windows with an NVIDIA GPU. macOS and Linux run, but haven't been tried on real footage yet.
  • The agents use your Claude subscription's limits. A long video takes several long turns, and you see the cost of every stage as it happens.
  • Speech-to-text is tuned for English.
  • FCPXML and OTIO exports carry the cut, not the overlays.
  • Overlays are React components rendered with Remotion. Changing their look means editing a template's code, which the agent can do for you.
